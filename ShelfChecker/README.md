# تطبيق فحص ومطابقة أسعار الأرفف (ShelfChecker)
### مخصص لأجهزة Honeywell EDA51 بنظام Android
**شركة العصلي للتجارة (Al-Assali Trading Co.)**  
**المطور:** عبدالله الخطيب  
**الحزمة:** `com.alassali.shelfchecker`

---

## 📌 نبذة عن التطبيق
تطبيق أندرويد فائق السرعة وخفيف الوزن مخصص لأجهزة مسح الباركود المحمولة باليد (Honeywell ScanPal EDA51)، يقوم بمطابقة فورية لأسعار الأرفف المعروضة في المعارض مع أسعار البيع الرسمية الشاملة للضريبة في Odoo ERP.

---

## ✨ المميزات الرئيسية
1. **التقاط مباشر للباركود (Hardware Keyboard Wedge):**
   - ماسح الليزر في جهاز Honeywell يلتقط الباركود ويرسله للتطبيق مباشرة دون الحاجة للضغط على أي حقل إدخال عبر `ScannerHelper.kt`.
2. **شاشة تفاعلية كاملة:**
   - **أخضر + نغمة تأكيد:** عند مطابقة السعر.
   - **أحمر + زر فروقات:** عند وجود فرق بين سعر الرف وسعر النظام، مع زر ضغطة واحدة لإضافة الصنف لقائمة الفروقات.
   - **برتقالي + نغمة تحذير:** عند عدم وجود الصنف بالنظام.
3. **وضع العمل دون إنترنت (Full Offline Mode):**
   - قاعدة بيانات محلية مدمجة `PriceDatabase.kt` (SQLite) تسمح بتنزيل كافة أسعار أودو والعمل بها داخل المستودعات والمعارض حتى لو انقطع الاتصال بالإنترنت.
4. **نظام حماية وتفعيل الأجهزة:**
   - التطبيق مقيد بنظام ترخيص مرتبط بالـ `Android ID` للجهاز عبر `generate_device_key.py` لحماية أسعار الشركة من العمل على أجهزة غير مصرح لها.
5. **تصدير وإرسال تقارير الفروقات:**
   - إرسال قائمة الباركودات غير المطابقة مباشرة من الجهاز إلى إيميل الإدارة أو حفظها كملف CSV لطباعة استيكراتها الجديدة فوراً عبر برنامج `ShelfLabelPrinter`.
