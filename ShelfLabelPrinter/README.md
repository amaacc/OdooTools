# برنامج طباعة ملصقات بيانات الصنف على الرف (Shelf Label Printer)
### شركة العصلي للتجارة

---

## 📌 نبذة عن البرنامج
تطبيق مكتبي متكامل واحترافي تم تصميمه خصيصاً لطباعة ملصقات واستيكرات الأسعار وبيانات الأصناف على الرفوف بمقاس **6×4 سم** على **ورق A4 عادي (21 ملصق في الصفحة)** مقسمة إلى 3 أعمدة و 7 صفوف مع علامات وخطوط قص دقيقة.

البرنامج يتصل مباشرة بنظام **Odoo ERP** الخاص بالشركة عبر بروتوكول JSON-RPC المشفر وفائق السرعة، ويعتمد السعر شامل الضريبة من حقل `list_price` بدون أي زيادة أو حسبة، مع استخدام **رمز الريال السعودي الجديد الرسمي (⃁)** وفقاً لأحدث دليل هوية للبنك المركزي السعودي (ساما).

---

## ✨ المميزات الرئيسية
1. **قراءة ومسح فوري بالباركود:**
   - متوافق مع قارئات الباركود اللاسلكية والسلكية (USB Barcode Scanner Wedge).
   - بمجرد مسح الباركود، يتم جلب بيانات الصنف فوراً من Odoo وعرضه بالجدول والمعاينة مع تشغيل نغمة تأكيد.
   - إذا تم مسح نفس الصنف مرة أخرى، تزيد الكمية تلقائياً.

2. **التكامل مع أجهزة Honeywell EDA51:**
   - زر خاص لاستيراد ملفات الفحص المرسلة من أجهزة Honeywell (`CSV` أو `TXT`).
   - جلب بيانات جميع الأصناف دفعة واحدة بسرعة البرق (Bulk Fetch).

3. **لصق سريع للباركودات:**
   - نافذة خاصة للصق قائمة باركودات من الحافظة أو ملفات إكسل بضغطة زر واحدة.

4. **ترويسة بشعارين (Logo 1 & Logo 2):**
   - ترويسة مقسومة تضم شعار الشركة وشعار الهوية التجارية، مع إمكانية تغيير وتحديد أي صور شعارات أخرى من نافذة الإعدادات.

5. **دقة طباعة عالية (300 DPI):**
   - توليد باركود Code 128 بأعلى معايير الدقة والحدة الرقمية لضمان قراءته السريعة من أي زاوية بواسطة أجهزة المسح.
   - معالجة وتشكيل كامل للحروف العربية وعلامات الترقيم باللغة العربية والإنجليزية.

6. **توفير الورق وعدم الهدر (Start Position):**
   - إمكانية تحديد موضع بدء الطباعة في الصفحة من الملصق رقم (1 إلى 21)، مما يتيح لك الطباعة على ورقة سبق وأن قُصت منها بعض الملصقات دون إهدارها!

7. **تصدير وطباعة:**
   - **طباعة فورية:** إرسال مباشر للطابعة الافتراضية بنظام ويندوز.
   - **تصدير ومعاينة PDF:** حفظ ملف PDF جاهز بدقة 300 DPI للمعاينة أو الطباعة لاحقاً.

## 🚀 طريقة التشغيل
يمكنك تشغيل البرنامج بأحد الخيارات التالية:
1. **بالنقر المزدوج على ملف التشغيل:**
   `run_printer.bat` الموجود داخل المجلد `c:\OdooDB\ShelfLabelPrinter\`
2. **عبر سطر الأوامر:**
   ```bash
   cd c:\OdooDB\ShelfLabelPrinter
   python main.py
   ```
